# JobPortal – Part 7  

📊 **Day 53 of #100DaysOfCode (Skill Shikshya Journey)**  

In Part 7 of the Job Portal project, I worked on the **Recruiter Dashboard**, focusing on job retrieval and editing features.  

---

## ✅ Features Implemented
1. Displayed all job posts created by recruiters in their dashboard.  
2. Enabled recruiters to **retrieve job details** from the database.  
3. Implemented **Edit Job** functionality for updating job posts.  

---

## 📚 What I Learned
1. Querying and retrieving job posts with **Spring Data JPA**.  
2. Binding **form data** with Thymeleaf to update job entities.  
3. Implementing **edit/update functionality** in controllers and repositories.  
4. Making the dashboard more **dynamic and recruiter-friendly**.  

---

## 🛠 Tech Stack
1. Spring Boot 3.5.5  
2. Spring Data JPA  
3. Thymeleaf  
4. Java 21  
5. MySQL
