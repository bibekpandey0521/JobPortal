# JobPortal – Part 9  

🚀 **Day 55–57 of #100DaysOfCode (Skill Shikshya Journey)**  

Over the last three days, I have been developing the **Job Seeker Dashboard** with **search** and **apply** functionalities.

---

## ✅ Features Implemented
1. Created **JobSeekerApply** and **JobSeekerSave** entities.  
2. Developed **controllers** for searching and applying to jobs.  
3. Implemented **search feature (Part 1 & Part 2)** to filter jobs by title and category.  
4. Integrated partial UI for **job listing and filtering**.  

---

## 🧩 Work in Progress
- **Part 3 & 4:** Completing the Job Apply functionality and refining the Job Seeker Dashboard.  
- Adding UI improvements for a smoother job search experience.  
- Validating user input and enhancing the controller logic.  

---

## 🛠 Tech Stack
1. Spring Boot 3.5.5  
2. Spring Data JPA  
3. Thymeleaf  
4. Java 21  
5. MySQL  

---

## 📚 What I Learned
1. Creating relational mappings for **Job Seeker and Job Entities**.  
2. Managing **search queries** efficiently with JPA.  
3. Structuring controllers for **search and apply workflows**.  
4. Designing progressive implementation steps for complex modules.
