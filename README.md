# JobPortal – Part 6  

💼 **Day 52 of #100DaysOfCode (Skill Shikshya Journey)**  

In Part 6 of the Job Portal project, I implemented the **Job Posting feature** with JPA entities, controller updates, and form integration.  

---

## ✅ Features Implemented
1. Created **JPA entities** for job posts.  
2. Enhanced **ActivityController** to support new job postings.  
3. Integrated **HTML form** for recruiters to post jobs easily.  

---

## 📚 What I Learned
1. Mapping job-related entities with JPA.  
2. Handling form submissions with Spring MVC & Thymeleaf.  
3. Linking controllers with entity services for data persistence.  
4. Building recruiter-friendly forms for job creation.  

---

## 🛠 Tech Stack
1. Spring Boot 3.5.5  
2. Spring Data JPA  
3. Spring MVC  
4. Thymeleaf  
5. Java 21  
6. MySQL
